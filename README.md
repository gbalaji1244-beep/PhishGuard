# 🛡️ PhishGuard - Phishing URL Detector

PhishGuard is a web-based cybersecurity tool that analyzes URLs and identifies potential phishing threats.

## 🚀 Live Demo

https://phishguard-0vei.onrender.com

## ✨ Features

- Analyze URLs for potential phishing threats
- Displays risk level and risk score
- Shows reasons for the security result
- Simple and user-friendly interface
- Flask-based backend
- Deployed online using Render

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Gunicorn
- GitHub
- Render
